Questions

Does it cost anything to add Fare?

No. Adding Fare to your server is free. A Premium module exists for extra features, and the support server can tell you what it includes.

Why does the invite ask for Administrator?

So every module works right after you add it, including moderation, security and voice tools. If you prefer, you can lower the role's permissions afterward and grant only what the modules you use need.

What is the prefix?

The default prefix is a comma, so the help menu is ,help. Server admins can change it from the Bot Settings module.

Does Fare use slash commands?

Fare is built around prefix commands. Users you trust can also be given no-prefix access.

Something isn't working. Where do I get help?

Join the support server and post in the help channel. Include the command you ran and what you expected to happen.

Privacy policy

Fare stores the settings you configure and the data its features need to work, such as Discord user, channel and role IDs for XP, AFK, giveaways, tickets and logs. Fare does not sell your data. To have your server's data removed, remove the bot and ask in the support server.
